# v0.1.0

## 版本信息

- 版本：0.1.0
- 日期：2026-11-25
- 包名：`dsh-kylin-toon`
- 运行时：DSH / QiLin / KCoder，Node >=20
- 渲染依赖：`hyperframes@^0.9.81`（Apache-2.0）

## 新增

- 小说工作台：七份结构文档、世界观/人物/大纲、章节蓝图→草稿→审稿→定稿、章节预览/筛选、行内修改意见、划词修改。
- 短剧漫剧：`MOTION.md` 契约、分镜质检、版本快照、节奏配方、模板包、复刻计划、Hyperframes HTML 工程、官方 Studio 反代与中文界面。
- 互动游戏：八阶段证据轨、PRODUCT_BRIEF 表单、概念三选一、构建快照、盲玩隔离、游戏画布。
- 视频解说：原片/解说稿工作台与预览。
- 技能：`toon-workbench`、`toon-novel`、`toon-drama-director`、`toon-video-pipeline`、`toon-hyperframes`、`toon-reference`、`toon-game`。

## 变更

- 短剧渲染栈改用 Hyperframes HTML→MP4；自研时间线/ffmpeg 装配仅保留旧工程兼容。
- 工作台页签只显示当前工作区实际存在的作品类型。
- 预览在文件版本变化且无未保存改动时自动刷新（4 秒轮询 + 窗口聚焦）。
- Studio 默认中文、可切英文；左上角仅显示 `dsh-kylin-toon`，移除安装桌面版入口。

## 修复

- `章节/` 文件读取 403；
- 任意剧集 ID（如 `原故事第一集-白衣入宫`）被 `/drama` 拒绝；
- 划词工具条因输入框内部滚动自动关闭；
- MV 闸门不识别 `delivery/*_1080p.mp4`、`S18a` 后缀镜头、封面/封底；
- 大于文本上限的成片 MP4 被工作区扫描丢弃。

## 兼容性与升级说明

- 首次安装依赖后需重启一次 KCoder/DSH 才会加载新路由与前端 bundle。
- 旧工程的 `toon_assemble` 仍可用，但新集默认走 Hyperframes。

## 验证

- `npm test`：90/90 通过。
- `npm run build`：`client.js` 构建通过。
- 实测：MV 工程 `delivery` 两版成片进入 outputs，G1–G4 通过；小说章节预览/划词/自动刷新；Hyperframes Studio 反代跨源 iframe 加载。

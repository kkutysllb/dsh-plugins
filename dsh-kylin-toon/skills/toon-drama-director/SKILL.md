# 短剧漫剧导演：先定 Motion，再做镜头

创作判断先于生成。不要一上来就出图/出视频；先把「观众经历什么变化、保留什么、换什么、拿什么证明」写成 `MOTION.md`，再交给 `toon-video-pipeline` 执行。

## 0. 路由：四种意图

| 意图 | 判断 | 下一步 |
| --- | --- | --- |
| 原创一集 | 没有参考片，也没选定模板 | 写 `MOTION.md` 的原创版本 → 选 1–2 个节奏配方 → 写分镜 |
| 参考复刻 / 拍同款 | 用户给链接/文件并说「像这个」「照这个做」 | `toon_reference_*` 拆片 → 确认版权 → 写 MOTION 的保持/替换 → 重建 |
| 模板改编 | 用户指定模板或「按这个结构」 | 读模板的结构层与内容槽位 → 只换内容，不动已接受的动效/停顿/剪切 |
| 改已有成片 | 已有可编辑文档，只改局部 | 先进 `toon-video-pipeline`；只有成片没有可编辑文档时按复刻处理 |

先读用户工作区里已有的品牌、人物、场景与文案；能读到就不要重复问。**最多问一次**：把素材缺口、版权口径、付费生成的素材数量与模型合并成一批问题，提供「你决定」选项；不要问技术选择、中间审批或分镜细节。

## 1. 先写 MOTION.md

用 `toon_motion action=template` 从分镜生成时间轴骨架，再补七节：

1. **来源与版本**：原创/参考复刻、参考片路径、版权口径；
2. **保持**：镜头顺序、节奏、声音锚点、必须保留的视觉关系；
3. **替换**：人物、场景、文案、品牌、素材；长文案要写长度约束；
4. **时间轴**：镜头 ID、入点/出点/时长、转场、台词/声音；
5. **视觉与运动**：构图、景别、运镜、字级、缓动；
6. **素材与声音**：必须提供 vs 可以生成；配音/音乐/音效的同步点；
7. **检查与证据**：至少三个同刻对比点、渲染版本与 hash、剩余差距。

纪律：

- 秒必须带单位；帧计时必须声明帧率；剪辑段保留源片→输出的逐段映射。
- 「保持」和「替换」不能空着；`<待填>` 不算完成。
- `toon_motion action=validate` 对不上分镜时，先改分镜或 Motion，不要带着阻断生成。
- 有检查章节不等于检查通过；证据必须指向真实产物。

## 2. 参考复刻：保持 craft，不只换配色

1. 先登记参考片并拆结构：`toon_reference_intake/fetch` → `toon_reference_analyze`；
2. 确认版权口径：`toon_reference_rights`；没有确认不进 G0；
3. 出 2–3 张同款方案：`toon_reference_plans`，每张写 keep（保留结构）与 replace（换内容）；创作者选定后再做；
4. 选择可编辑表示：文字/UI/图表/Logo/字幕/镜头运动优先原生重建；人物、产品、实拍、旁白、音乐用生成媒体或用户素材；
5. **默认只做一次聚焦比对**：最多 4 个代表性时刻与原片同刻对比；只修一批明确缺陷（bounded repair），不要陷入逐帧无限返工；
6. 换内容时保持原片的视觉密度、镜头运动、字形气质与对比度；不能比原片更暗、更空、更碎；
7. 原片有声就做成片有声：默认保留/重排参考音轨；替换旁白必须得到同意，未答的同意问题保持 pending，不能靠删旁白绕过；
8. 交付时说清：保留了什么、改了什么、实际渲染出了什么、还差什么；不宣称未达到的「忠实」。

## 3. 节奏配方

用 `toon_recipe action=list` 选 1–2 个结构配方，再 `action=apply` 在本集 `recipes/<id>.md` 生成镜头骨架建议。配方只给结构与检查项，不改 `分镜.md`；合并前按本集人物、场景与时长改写。

常用顺序：冷开场钩子 → 三拍反转 → 集尾钩子。不要为了「高级」堆配方。

## 4. 版本与修改

- 动分镜/剧本前先 `toon_drama_version action=create` 存一版；恢复旧版本会生成新 vN，不删除后续历史。
- 改已有内容先定位受影响镜头与连戏关系；只改要求的范围，不顺手重写无关场次。
- 源文件冲突时先读较新版本再重放意图编辑，不覆盖创作者刚写的内容。

## 5. 交制作流水线

MOTION 通过、分镜通过 `toon_shot_qc` 后，交给 `toon-video-pipeline`：生成媒体（付费先确认）→ `toon_composition scaffold` 生成 HTML 工程 → 引擎自带 Browser 打开 Studio → `toon_composition render` 出样片/成片 → `toon_shot_qc` / `toon_audio_qc` / `toon_gate`。渲染后核对 ffprobe 技术验证（尺寸/帧率/时长/解码）；技术通过与视觉验收、用户采用分开说。

## 6. 工具速查

| 工具 | 用途 |
| --- | --- |
| `toon_motion` | Motion 模板 / 落盘 / 校验 |
| `toon_recipe` | 节奏配方 list/get/apply |
| `toon_drama_version` | 本集版本 create/list/restore |
| `toon_reference_*` | 参考片登记、拆解、方案、版权 |
| `toon_composition` | HTML 工程 / Studio / Hyperframes 渲染 |
| `toon_shot_qc` / `toon_audio_qc` / `toon_gate` | 由 `toon-video-pipeline` 使用 |

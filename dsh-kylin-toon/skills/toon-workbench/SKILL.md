# KToon 创作台

界面跟着文件走：工作区里出现创作文件，右侧对话旁边就会出现对应页签；没有创作文件时，界面保持原生对话，不占位置。

## 目录约定

| 工作台 | 识别 | 作品文件 |
| --- | --- | --- |
| 小说 | 根文件 `正文.md` `设定.md` `小节大纲.md`，或目录 `正文/` `大纲/` `设定/` `追踪/` `对标/` `参考资料/` | Markdown |
| 短剧漫剧 | `剧集/<EP>/` 或根目录 `short-drama.json` | 每集最多五份：`剧本.md` `视觉设定.md` `分镜.md` `图片提示词.md` `视频提示词.md`；装配阶段可加 `剪辑单.md` |
| 互动游戏 | `game-adaptations/<project>/` | `PRODUCT_BRIEF.md`、`analysis/`、`concepts/`、`design/`、`build/`、`qa/`；可玩构建 `build/app/index.html` |
| 视频解说 | `video-recaps/<project>/` | `sources/` 原片、`work/` 中间物、`outputs/` 成片、`narration.json` |

只建需要的文件：没写就不建，没要求的阶段不补。旧的结构化工程（`short-drama.json` v0.5）原地保留，界面不改写它。

## 界面

- 顶部只显示当前工作区识别到的作品类型页签：小说 / 短剧漫剧 / 互动游戏 / 视频解说；没有对应工程时该页签不渲染，其他工作区不会出现 KToon 页签。
- 小说「章节工作台」在阶段卡片下方：可按状态筛选、点整行预览主稿（自动切到文稿）、逐份预览蓝图/草稿/审稿/定稿，并可写行内「提修改意见」发给 Agent；`章节/` 也在左侧文件树中。文稿预览支持划词修改：选中文字后可填修改要求，直接发给 Agent。磁盘文件被 Agent 改动后，预览在无未保存改动时自动刷新（4 秒轮询 + 窗口聚焦刷新）。
- 短剧页：剧集切换、制作（镜头与素材）、文稿、质检与闸门；编辑保存走版本校验，冲突会提示而不是覆盖。
- 游戏页：阶段轨（立项→拆书→概念→设计→灰盒→美术→构建→验收）、下一步卡、试玩（沙箱 iframe + 构建快照回滚）、阶段（PRODUCT_BRIEF 表单 / 概念三选一 / 模板 / 盲测交接）、文稿分组、画布（阶段/文稿/构建/快照/盲测节点，可拖拽缩放）。入口先跑 `toon_game_intake`，阶段判断只认文件证据。
- 视频页：预览、文稿、制作详情；解说分段与时间轴分开，改文字不改时间。
- 收起后角落留一个小入口；选择按工作区记住。

## 媒体生成

本插件不实现媒体通道、不存密钥。出图/出视频/配音/配乐由宿主里已安装的多媒体网关插件提供（`media_*` 工具）。网关没配置时，创作台照常写剧本、分镜和提示词，只是不生成媒体。

付费前必须先在对话里列出任务与参数，得到确认再提交。

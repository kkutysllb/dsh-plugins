## 新增

- **global 模式 LLM 分批打分**（0203 §2.2 兑现）：社区数 >8 时摘要按 10 个/批送 LLM 打 0-10 分（词法兜底单批失败），`QueryMeta` 透出打分调用数与 token 数；≤8 社区保持零 LLM 直进；
- **RPC 四新端点 + 面板配套交互**：`communities`（社区列表：摘要 + 成员实体）、`evidenceText`（点击邻居边展开源 chunk 原文——0207 §3.3 两个"遗留下批接"至此接完）、`estimate`（索引前 dry-run 成本估算）、`forgetGraph`（KB 级图谱遗忘）；
- **面板五件套**（0207 §3.1/3.4 契约点）：KB 卡片健康度三色灯（绿=新鲜 黄=有陈旧 红=有隔离/未建）、索引进度 token 计数显示、索引前 dry-run 成本预估卡（确认后才启动）、KB 级遗忘（二次确认）、隔离区重放按钮（体检页/审查页，带成本确认）；
- **审查统计持久化** `review.json`（每 KB：sampled/correct/corrected + 低置信区间 <0.8 单列），重启不丢；
- **体检报告扩展**：低置信区间单独精确率、roots 外逃逸检查（absPath 已不在任何授权根内的来源数）；
- **薄 d.ts 类型产物**（0205 §4「或手写薄 d.ts」兑现）：`src/dts/` 手写 seam 契约类型面随构建拷贝进 `lib/*.d.ts`，package.json exports 挂 `types`——TS 消费方获得类型；
- **评测体系 v2**：questions v2.1（45 题 = 40 + 5 道多跳 local 题，golden 由 spec 两跳路径派生，changelog 版本化）；MRR@5 排序敏感评分器（自带 3 项单测）；门槛 v2（local 非劣性 / global 绝对差 +0.05 / traversal 双下限）；记分卡新增库体积成本指标。

## 变更

- **local 检索排序重做**（种子权重精化）：反查种子权重由原始出现次数改为**文档秩加权和**（rank r 命中块贡献 1/r——原 count 被枢纽实体与 sitemap 类枚举页污染，实测「对账」曾以 count=14 压过词法直击权重 12 排到第 1）；呈现序由严格分层改为**种子分 ⊕ PPR 分凸组合**（各按最大值归一各占一半）——问题点名实体（词法直击）与图邻近实体（多跳桥接）各执一半。MRR@5 0.5739→**0.6771**（结构上限 0.6944 的 97.4%），多跳题 0.3322→**0.5778**，relationRecall 顺带 0.95→1.00；
- **种子集合计 ≤12 截断**（0203 §2.1 原设计）：chunk FTS 反查路径此前不设上限（曾扩散到 17 个种子使 PPR 退化为度数排序），现按「FTS 直击优先 + 反查按秩加权和补足」截断；
- **KB 默认解析链**：query/traverse/forget 的 cwd 参与解析（0207 §2.2 ①），顺序对齐设计（cwd 命中唯一库 → 唯一库 → KB_AMBIGUOUS 候选）；`KbRegistry.byCwd` 对库根做 realpath 双形态比较（macOS `/var` vs `/private/var` 前缀差异）；
- 面板 runtime 通知文案全部经词典（双语自适应），不再硬编码中文；
- **设计文档全量回写**（0201-0206）：角色表实测形态（config.ts→rpc/client）、契约 v2（KbRef/cwd）、错误码全集（+KB_AMBIGUOUS/INVALID/LLM_TIMEOUT/CONTEXT_WINDOW）、GraphStore 同步接口与 relation_evidence 表、Parser 提前落地、global 打分、种子秩加权与凸组合、并发形态（indexBackground 主路径）、适配实测链、package.json 实态、oracle/questions v2/门槛 v2 全文与首测数据——各文档附「实现修订记录」章节，文档-代码漂移清零。

## 修复

- **cwd 默认知识库解析是死代码**：seam 契约声明 query/traverse/forget 第三参 cwd，实现签名不收——多库场景下 cwd 命中唯一库不会自动选中、直接抛 KB_AMBIGUOUS（审计 A1）；
- **审查判"错误"的关系未从检索面过滤**：排除态（confidence=-1）此前仍出现在 graphrag_query 证据与 graphrag_graph 子图中；现 neighbors/relationsAmong/sampleRelations 三路过滤且重启不复活（审计 A2，0207 §4.2）；
- **别名不参与词法召回**：entity_alias 此前只写不读；现新别名落地即重建实体 FTS 行（展示名 + 全部别名，审计 A3，0202 §3）；
- **CONTEXT_WINDOW 块对半细分未实现**：现按 0203 §1.5 落地——失败码独立映射 → 就近行边界切半各抽一次 → mention span 带偏移还原整块坐标；半块再失败按原语义隔离（审计 A10）；
- **库文件权限 0600**：SQLite 库文件创建即收紧到属主读写（0202 §7）；
- **面板「导入文件」按钮点击必抛 TypeError**：`runtime.bridge` 未在 KbRuntime 接口接线（审计 A9，tsc 盲区漏检的历史缺陷）；
- **评测 v2 题集两处实体名笔误**：L18「风控」（2 字构不成 trigram，属无效题面）→ 风控服务；L20「营销服务」→ 促销服务；题面/golden 实体组/golden 关系端点一并对照 spec 修正（changelog v2.1）；
- **client 类型盲区正式关闭**：client tsx 纳入 tsc（tsconfig include），修掉 7 处历史/新增类型错误（含 ProgressView.report 协议漂移、KnowledgeSource 未定义、slots 收窄）——此前两度导致真机整页崩溃的盲区类别不再存在。

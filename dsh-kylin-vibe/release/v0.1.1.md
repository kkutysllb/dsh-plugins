上一版（v0.1.0）交付了 GraphRAG 核心引擎、agent 五工具与 Web 面板的基础闭环（建库→索引→浏览→抽查→体检）。本版本聚焦**用户实际使用中反馈的十二项改进**：让建库更省事（目录选择器、Agent 代建）、让验证更可信（滑选更正闭环）、让知识库可运营（知识管理页签），以及一批真实宿主上暴露的缺陷修复。

---

## ✨ 新功能

### 1. 创建知识库：目录选择器
新建表单不再要求手输绝对路径。新增「选择目录」按钮，走宿主目录选择链（桌面桥 → `uiWorkspace.pickDirectory`），选中即回填；用户取消则静默返回，不打扰。宿主服务缺席时内联提示而非静默失败。

### 2. Agent 代建知识库
「不知道怎么建库」的答案——一键把建库任务交给 Agent：
- 表单新增「Agent 代建」按钮，空状态新增「让 Agent 代建」入口（无目录时引导 Agent 扫描工作区挑目录并征求确认）；
- 提示词**自包含**（目标/步骤/验收标准/停止条件），Agent 接手后自动 `graphrag_status` 探查 → `graphrag_index(create=true)` → 审批门挂起等用户批准（fail-closed 设计行为）；
- 投递四级降级链：自动发送（submitted）→ 草稿档（draft，已写入输入面供检查后手动发送）→ 剪贴板（copied）→ 失败提示（none），**绝不假报成功**。

### 3. 代建落点：工作区选择 + 会话模型选择
新建表单新增两个下拉：
- **工作区**（Agent 代建落点）：列表来自宿主 workspaces 服务，缺省跟随当前会话；跨工作区时自动新建承接会话；
- **会话模型**：目录来自宿主模型服务（`remote.session.modelCatalog` 归一化），经 `modelDirectories` 做会话级 durable 选择（与输入框选择器同源），缺省跟随会话默认。

### 4. 准确性抽查：滑选驱动的更正闭环
抽查判定「错误/存疑」后不再只是排除——现在能**直接改图**：
- 在证据原文上**鼠标滑选**一段文字 → 浮出「更正所选」浮标 → 所选文字送模型跑同款 SPO 抽取 → 三元组自动预填编辑器 → 确认提交（字段仍可手改；解析失败提示手动填写）；
- 更正落图语义：端点实体按名 upsert（缺失建 concept），置信度置 1（人工确认）并清除排除态，全量重算度数；
- 体检报告新增「已更正」统计行（更正不再计入排除）。

### 5. 知识管理页签
浏览视图新增第四页签，构建好的知识库从此可运营：
- **补充新知识**：粘贴 markdown 文本（标题可选）→ 落 `notes/` 盘 → 后台增量索引（自动抽取实体关系，卡片实时显示阶段）；笔记目录自动并入授权根（存在才并入，防 ENOENT）；
- **已入库来源表**：全部来源的状态一览（merged/extracting/failed…），行级删除（确认框 → 图谱级联清除 + 笔记物理文件一并删除）；
- **授权目录编辑**：每行一个绝对路径，保存即写回 `kbs.json`（配合顶部「索引」按钮收编新文件）。

### 6. graphrag_index 工具后台化
`graphrag_index` 工具改为**后台启动、立即返回** `{started, note}`（started=false 表示已有索引在跑），描述引导用 `graphrag_status` 轮询进度。Agent 调用不再被宿主工具调用预算掐断（修复项 2 的根治手段）。

## 🌟 体验优化

1. **审查证据块 markdown 渲染**：证据原文经宿主 `MarkdownText` 渲染——甘特表、加粗、标题全部成富文本（表格/流程类语料的可读性质变）；渲染组件运行时软取宿主单例，缺席宿主自动回落 `<pre>` 原文。证据区限高内滚。
2. **面板内滚动**：适配宿主 0.2.0-rc.2 main 槽位 `overflow:hidden` 定高契约——长内容（浏览页 4000px+ 实测）在面板内滚动自如，不再被裁切。
3. **动作按钮排间距**：同排换行 `row-gap`、相邻排 `margin-top`——窄面板下两排按钮不再上下紧贴。
4. **知识管理表单样式**：标题/正文输入框全宽、label 独立成行、带占位提示（修复首版标题正文挤成一行散架的问题）。
5. **检索证据更充实**：关系证据去重后单条上限 4→12，同样的卡片看到更多原文引用。
6. **移除两处空白占位按钮**（浏览页签行、审查卡片），界面不再有无功能的裸按钮。

## 🐛 bug 修复

1. **Agent 代建后停在空白会话**（症状：代建点击后视图不跳转，看不到提示词）
   根因：`sessions` 服务没有 `open()` 方法——视图导航归 ui-workspace 所有（"navigation belongs to the view owner"）。
   修后：`navigateToSession()` 走 `uiWorkspace.openSession()` 正路；剪贴板降级路径同样导航。实测：刷新→面板空态代建→视图落在接收会话，提示词可见且 Agent 立即开工。

2. **agent 调 graphrag_index 卡 5 分钟后被 abort**（症状：工具调用 5 分 33 秒后 "Error: tool call aborted"）
   根因：工具在调用内前台 await 整个 ingest，大语料远超宿主工具调用预算。
   修后：改调 `indexBackground` 立即返回，ingest 与面板同走后台管线；测试改为轮询 progress 至 done 再断言。

3. **别的进程建的库看不到**（症状：桌面端/KCoder 建的 AIDC 库，web 面板列表里没有）
   根因：`KbRegistry` 装载一次后永不重读，多宿主共享 dataDir 时互相不可见。
   修后：list/byId/byName/byCwd 前按 mtime 变化重读 `kbs.json`（读失败保留内存态），save 同步 mtime。

4. **审查卡片同一 path:lines 显示重复片段**（症状：一条证据出现 2-3 块相同内容）
   根因：`relationEvidence` 的 LEFT JOIN mention 扇出——同 chunk 内端点实体各有多条 mention 时一条证据被翻成多行。
   修后：按 chunk_id 去重（保留最早 span），一条证据 = 一个 chunk；新增双端点三 mention 回归测试。

5. **证据 markdown 原文裸奔**（症状：表格/加粗全部显示为原始符号）
   根因：宿主 memo 组件是 `$typeof` 对象形态，`typeof === 'function'` 守卫判定失败走了回落。
   修后：双形态判定（函数与 $typeof 对象均可识别），正确取到宿主 MarkdownText。

6. **知识管理笔记路径判定失效**（症状：已入库笔记不显示标记/删除不净）
   根因：macOS tmpdir realpath 差异（`/var` vs `/private/var`）导致前缀比较失败；notes 目录不存在时并入授权根触发 scanner ENOENT。
   修后：realpath 规范化后比较；notes 目录仅 `existsSync` 时并入授权根。

## 兼容性与升级说明

- **`graphrag_index` 工具返回语义变化**：从「等待索引完成后返回报告」变为「立即返回 `{started, note}`，进度用 `graphrag_status` 轮询」。依赖旧阻塞语义的自动化脚本需要适配（面板与 Agent 默认提示词已同步）。
- 升级方式：`dsh plugin --profile web add dsh-kylin-vibe`（或 GitHub/镜像渠道，见 README）后重启 `dsh web`（或 KCoder / QiLin）生效。
- 数据兼容：kbs.json / graph.db 布局与 v0.1.0 完全一致，原地升级无迁移。

## 已知限制与下版预告（v0.1.2 排期）

- **二进制文档解析**（DOCX/PPTX/XLSX/PDF）尚未支持——当前这些文件标记 failed 并入来源表（md/文本类正常）。调研已定稿：fflate（zip+xml 家族）+ unpdf（PDF）+ 宿主附件服务视觉链路（图片多模态抽取）。开发分支 `wip/doc-image-extraction` 已就绪。
- AIDC 类以 .docx/.pdf 为主的语料，建议等 v0.1.2 后重建知识库。

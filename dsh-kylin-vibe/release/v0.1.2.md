上一版（v0.1.1）交付了面板易用性与审查闭环。本版本是排期裁定的 **v0.1.2 三条主线**全量落地：①让知识库吃得下更多语料形态（DOCX/PPTX/XLSX/PDF/图片多模态抽取）；②让知识库可运营（文档导入、来源管理表、变更同步、召回测试）；③让图谱看得见摸得着（浏览页双列布局 + 全量图谱视图，并在用户上报「无法阅读无法操作」后整体重做布局与交互）。

---

## 新增

### 1. 二进制文档与图片知识抽取（core）
- **DOCX / PPTX / XLSX**：fflate 解压 + 手写 OOXML 文本面（`w:p/w:t`、`a:p/a:t` 按页、sharedStrings 表格），零新依赖；
- **PDF** 与**图片多模态**：图片资料走模型视觉抽取，与文档抽取同一套实体-关系落图管线；
- 扫描器按扩展分发，新语料形态入库即被索引与检索。

### 2. 知识库管理面（知识管理页签全量）
- **文档导入**：目录选择器选目录 → 服务端复制进 `imports/files/`（带前缀防多根路径冲突）→ 后台增量索引；授权 = 用户显式挑选；
- **已入库来源管理表**：每来源的块/实体/关系贡献统计 + 类型/时间/错误列 + 行操作——重新索引（单文件续跑）、停用（FTS/chunksForEntities/relationEvidence 三路检索排除，diff 不触发重索引、恢复不回 pending）、删除；
- **变更检测**：扫描 diff 零 LLM，横幅展示新增/修改/删除计数，一键同步索引；
- **召回测试页签**：输入问题 → local 检索 → 证据 chunk 带分呈现（FTS bm25 直击优先、图谱邻近补足，topK 可调）。

### 3. 浏览页双列布局 + 全量图谱视图（Neo4j 风格）
- 左列实体卡、右列图谱，**两列宽度可拖拽**（localStorage 记忆）；
- 图谱数据 `graphAll` 与卡片头统计**同源**：节点=全部实体、边=全部关系，两处数字严格一致（含图例分类型合计）；
- **世界坐标系力导向布局**：黄金角螺旋初始布点（枢纽居中）+ 网格近场接触斥力 + Hooke 线性弹簧 + 微弱向心，收敛后自动缩放适配全图，布局期间取景跟手；2387 节点/2485 边实测布局期与闲置期均满帧率（120Hz 屏 121fps），离线仿真最挤网格从 81% 节点堆入一格降到最多 3 个——不再结块；
- **渲染管线**：id→节点/邻接表/枢纽序随数据构建一次（O(1) 查表）+ 脏标记渲染（收敛后每帧零绘制），滚轮/平移/悬停不触发 React 渲染；
- **可读性**：屏幕空间恒定字号标签（远景只标枢纽、放大后视口内全标，双主题晕圈）；图例点选做类型过滤（头部计数保持全量 +「已隐藏 n 类」标注，统计一致性不破坏）；搜索实体定位并自动居中；单击节点出详情卡（类型/度/邻居表带方向·关系·权重，点邻居跳转聚焦）；聚焦时其余节点置暗而非擦除；边悬停/点选高亮并标注关系类型·权重；
- **交互**：按下位移超阈值才算拖拽（点击不再误触）；滚轮 native 非被动监听锚定光标缩放；＋/－缩放按钮、适应视图、暂停/重排布局。

## 变更
- 图谱视图从「SVG 浏览子图（前 30 实体 + 一跳邻居）」改为 **Canvas 全量渲染**；「双击展开邻居/600 节点上限」等子图时代交互与文案移除；
- `browseEntities` 邻居补 `otherId/otherType`，`store.neighbors/relationsAmong` 补 srcType/dstType；
- client tsx 仍不在 tsc include（已知类型检查盲区，本版以独立 tsc 命令兜底；ManageTab 的 `KnowledgeSource`/`runtime.bridge` 类型欠账记录在案待后续把 client 纳入 tsc 项目）。

## 修复
- **图谱页面冻结**：绘制循环每帧 O(边×节点) 重建 Map（2387×2485≈1180 万次/帧）+ 收敛后常驻全量重绘 + 滚轮走 setState——三者叠加致滚轮/平移/点击全部卡死 → O(1) 查表 + 脏标记 + 热路径只读 ref；
- **力导向稀疏图坍缩结块**：FR d² 弹簧 + 平方斥力在稀疏图上把 81% 节点压进同一格（坨内斥力对称抵消、净力趋零冻结）→ 接触斥力（d<K 线性、d→0 有限持续）+ 线性弹簧；
- 图谱悬停 tooltip 的 CSS 类从未定义（永不可见）；图表面板头部 `pointer-events:none` 导致全部控制按钮不可点击；「暂停布局/重排布局」等 5 个按钮文案键在词典缺失（显示原始 key）；搜索下拉被图例遮挡（z-index 层级）；
- **LLM 流消费护栏**：空闲 90s / 总时长 300s 双超时，抽取流挂死不再拖垮索引；
- 页签行与动作行间距：相邻异类元素此前的同类相邻修复覆盖不到，补 margin-top。

## 删除
- Barnes-Hut 四叉树布局实现（网格配对在健康摊开形态下更快，代码一并移除）；
- 图谱子图时代的「双击增量展开」面板交互与 600 节点渲染上限残留文案（`expandNode` 服务端端点保留）。

## 兼容性与升级说明
- 插件接口无破坏性变更：`graphrag_*` 五工具、RPC 端点在 `graphAll`/`sources`/`recall` 等之上只增不改；
- 升级方式：`dsh plugin --profile <p> add dsh-kylin-vibe`（或 GitHub / dsh-plugins 镜像仓三渠道任一）后重启宿主；
- 旧库无需重建：已有索引继续可用；DOCX/PPTX/XLSX/PDF/图片等**新语料形态**需重新索引（或放入授权目录后点「索引」）才会收编。

## 新增

- **GraphRAG 核心引擎**（`src/core/`，零宿主依赖）：
  - 授权目录扫描（realpath 授权校验 / 默认排除 / hash 增量 diff）→ 分块 → LLM
    SPO 抽取（闭合类型集、置信度门、隔离区）→ 实体归并 → 加权 LPA 社区 →
    LLM 社区摘要，七阶段管线，断点续跑 + 后台索引 + 取消。
  - 存储：每 KB 一个 `node:sqlite` 库（WAL + FTS5 trigram），`kbs.json`
    注册表多知识库管理；旧单工作区布局自动迁移。
  - 检索三模式：local（FTS5 词法种子 + PPR 扩展）、global（社区摘要）、
    graph（BFS 多跳遍历）；证据纪律——所有结论回链 `path+lines` 原文。
- **Agent 工具面**（五工具）：`graphrag_query` / `graphrag_graph` /
  `graphrag_status` / `graphrag_index` / `graphrag_forget`；kb 参数多库选择；
  写操作审批门（dry-run 成本估算 + 双语 ask：审计 `reason` + 本地化
  `displayReason`）；headless 宿主自动拒绝时 fail-closed；稳定错误码表
  （含 `KB_AMBIGUOUS` 候选名单）；能力公告段（order 210）。
- **双语 Web 面板**（dsh/QiLin 同 bundle）：侧边栏入口 + 主面板；KB 卡片
  （建库 / 编辑 / 删除 / 索引进度实时条）；图谱浏览页（实体卡 + 邻居边 +
  原文引用）；准确性抽查页（低置信优先抽样，Correct/Wrong/Unsure 三判定，
  Wrong 关系检索期排除）；体检报告页（覆盖率 / 抽样精确率 / 排除清单）。
  - **语言自适应**：词典经宿主 locale 服务注册（`kyGraph` 命名空间）+ 活
    翻译器，随引擎语言切换即时跟随；无 locale 服务的宿主回落内置 zh。
  - **样式**：`--dsw-alias-*` 宿主设计令牌 + 字面量兜底双层变量，深浅主题
    自适应；布局纪律——壳层宽度与滚动归宿主，不自建侧栏/固定栏。
- **RPC 通道**：`/dsh-kylin-vibe`（webServer 前缀注册 + connection 鉴权围栏），
  snapshot/createKb/updateKb/deleteKb/index/cancel/progress/browse/
  sampleReview/review/health 端点。
- **双引擎 manifest**：`dsh.bundle.patch` + `qilin.bundle.patch` 同指一份
  `cordis.patch.yml`；client 注入面 `dsh.client` / `qilin.client` 一致
  （ui-renderer / connection / locale）。
- **评测体系**：冻结评测集（40 题 / 种子 42 可重放 fixture / oracle 抽取）；
  graph-full traversal 检索 P 0.945 / R 1.000（平铺 BM25 基线 F1 0.256，
  门槛 3 通过）；local/global 门槛因基线天花板结构性不可达，门槛 v2 已排期。

## 兼容性与升级说明

- 首个发布，无升级路径。
- **引擎要求**：dsh 0.2.0-rc.2 实测通过；QiLin 3.0.0+（带 dsh 兼容层）实测
  3.0.7。peerDependencies 全部 `*`（含 `@deepseek-ai/cordis` 等），刻意不
  收窄——预发布比较器与 QiLin 运行时版本语义均不保证 dsh semver。
- **产物形态**：Host ESM bundle（node:sqlite 需 Node ≥ 22.5）+ Web client
  CJS bundle（`window.__ModuleLoader__` 模块表契约）；client 注入
  `@deepseek-ai/dsh-client-ui-renderer/connection/locale`，宿主缺注入会
  激活失败（0.2.0 实测契约）。
- 数据目录：配置 `dataDir` > `GRAPHRAG_DATA_DIR` > `DSH_HOME` >
  `~/.dsh/graphrag`；索引语料必须显式授权（配置 roots 或面板建库）。
- 变更需重启宿主生效（client bundle 的 rev 在宿主启动时固定）。

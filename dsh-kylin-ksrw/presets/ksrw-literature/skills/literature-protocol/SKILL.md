# 文献协议（literature）

## 何时用

开题后需要建立相关工作、找基线、核对引用，或论文投稿前做引用审计时。

## 检索能力边界（重要）

- 你有 `web_search` 与 `web_fetch`：能做**公开网络**检索（arXiv、OpenAlex、PubMed、网页）。
- Scopus / Web of Science / EI Compendex / CNKI / ACM DL / IEEE Xplore 需要**机构订阅**，本工位没有订阅账号，无法直接检索或导出命中数。
- PRISMA 交付规则：公开来源给真实命中数；机构库行标「未执行（无订阅）」并留空，注明确需用户用机构权限回填；**不要**写成「本工位无检索工具」，也不要编造各库命中数。
- 检索与 PRISMA 是文献工位职责：若别的工位被要求做检索，回复应指向文献工位，而不是自己代做。

## 步骤

1. 读项目问题、开题方案与已有 literature/；先列检索问题，不要直接堆论文。
2. 检索：至少 3 组检索式（核心术语/同义词/相邻领域），记录来源与日期。
3. 筛选：按纳入/排除标准过标题与摘要；保留“必须引用/基线/对照/背景”四类。
4. 精读：每篇记录问题、方法、数据、指标、局限、可复用点；不要只抄摘要。
5. 做矩阵：论文 × 维度（问题/方法/数据/指标/局限），标出本项目的位置。
6. 证据绑定：每个关键主张用 ksrw_evidence 绑定 paper + 位置 + 原文；没有原文不得写“已有研究表明”。
7. 引用审计：检查正文引用是否都有条目、条目是否都被引用、年份/作者/DOI 是否一致。
8. 用 ksrw_propose 提交文献矩阵/综述提案；不直接改论文正文。

## 纪律

- 不把摘要当结论；不把综述当原始证据。
- 预印本要标注；撤稿/勘误要记录。
- 检索不到就写“未检索到”，不要编引用。
